# 大学系级课程排课系统｜MVP 验收矩阵

## 1. 验收结论

截至 2026-08-10，本机版本的账号、基础资料、Excel 导入、手工排课、冲突检查、个人课表和新周期恢复流程均已实现并通过回归。

当前结论为：**本地核心功能有条件通过，正式线上验收尚未通过**。

未完成的条件有两项：

1. 系统仍运行在单台电脑的 Next.js + SQLite；尚未部署公网，也未迁移共享 PostgreSQL，因此“任何地点访问”的正式多人环境尚不存在。
2. 教学周目前支持 All weeks、Weeks 1–4、Weeks 5–8，能满足已提供的 BED／DB 与 FED／PM 换课案例，但尚未支持 PRD 所述任意起止周区间。

## 4. 上线前必须完成

1. 支持任意教学周起止区间并补充重叠边界回归。
2. 由项目负责人选择托管平台与生产 PostgreSQL。
3. 迁移 SQLite 数据访问层并在共享测试环境执行双账号、跨浏览器协作验收。
4. 配置域名、HTTPS、数据库备份和生产环境密钥后再交付真实排课团队使用。

## 5. 首版明确不包含

- 自动或 AI 排课。
- 个人学生选课冲突。
- 学校统一登录。
- PDF/Excel 课表导出。
- 邮件或短信通知。
- 日常版本历史和任意旧版本恢复。
