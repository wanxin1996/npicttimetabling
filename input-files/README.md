# 待导入资料

请把以下三个文件放在本资料夹内：

1. `01-PT老师有空时间` — PT 老师可以上课的时间
2. `02-FT老师不可上课时间` — FT 老师不能上课的时间
3. `03-教室特殊要求` — 课程或教师对教室的特殊要求
4. `04-各年级课程清单.xlsx` — Year 1、Year 2、Year 3 分别有哪些课程

文件可以是 `.xlsx`、`.csv`、`.pdf` 或图片；建议保留上述编号开头，方便后续识别。每一类请只保留当前有效的一个版本。

这些资料文件默认不会被 Git 提交或上传到 GitHub；本说明文件除外。

## 课程清单处理方式

收到第 4 份 Excel 后，会先整理并核对：

- 每个年级的课程代码与课程名称
- 每门课对应的 programme、班级和 section 数量
- 每周次数、每节时长、教师及教室要求（文件中有提供时）
- 与系统现有课程、班级和排课数据之间的新增、修改与冲突

资料确认后，先备份当前数据库并在副本试运行，再更新系统和重新验证课表；不明确的行不会自动猜测或覆盖现有资料。
